# v0.7.0 · 首次公开源码

在浏览器里设计多色 3D 打印通行证和徽章：支持双面排版、图像与文字、图层集合、剪影和内外描边、指定目标裁切、真实三维预览，以及 3MF / 分色 STL 导出。

本次公开版采用 MIT，新增图文介绍、操作流程图、使用说明、贡献规则及静态/源码发行包。内部维护记录和私有历史不在公开仓。

在线体验：https://beatsanae.cn/pass/ · https://beatsanae.cn/badge/

静态包解压后需要 Node.js，可双击 start-preview.cmd 后通过本机网址体验；也可部署完整网站文件到 HTTPS 静态托管。作品进度仅在当前浏览器，建议下载项目 JSON 备份。

附带 A1 / 0.2 mm 喷嘴预设；其他设备和材料请在切片器调整。自动检查不等于保证可打印。源码基本构建与测试结果以仓库 Actions 为准；本次没有新增切片/实物验证。
