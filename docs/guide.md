# 使用说明

## 开始一份作品

打开官方通行证或徽章入口。两边会优先恢复各自上次进度；没有本机进度时，通行证使用内置案例，徽章使用默认底板。需要从头做时点击「新建」，可先保存当前项目。

通行证可选普通或精简模式。徽章的「底板」入口可调整预设轮廓、自由轮廓/节点、尺寸、孔洞、三层厚度和安装槽。

## 排版与层高

- 左侧集合负责正背面和物理高度；图层放在集合里，文件夹只帮助整理。
- 图案可移动、旋转、镜像、调整尺寸；多选可以整体缩放或对齐。
- 拖动时可用吸附和参考线；精确吸附可指定源/目标参照。
- 填充、轮廓宽度和内外描边位置是独立属性，预设、导入图案和徽章底板共用。
- 「覆盖底层」和「避让下方区域」作用不同；关闭覆盖会保留下方原实体，避让则裁去平面重叠区域。

## 导入图像与文字

图像支持 PNG、JPG、WebP、静态 SVG，单文件不超过 20 MB。选择精度、分色和剪影模式，检查预览再添加；关闭导入会取消正在进行的描图。

导入视野的缩放和拖动不改变实际毫米尺寸。普通 SVG 图案会先做安全处理，再解码描图；不保证无损保留 SVG 的全部编辑结构。徽章底板另有 SVG 填充矢量入口。

文字可选择内置字体或导入本地字体，设置毫米字号、字距、行距和多行对齐。字体可以随项目保存，分享项目时请确认其许可。

## 裁切与细小色块

裁切工具只影响同面指定目标，工具自身不打印；「反向裁切」只保留工具范围内的目标。隐藏切割块的视图开关不会自动停用切割。

三维里可以检查独立碎块和相连局部细条，按需转色、剔除或还原；处理记录随项目保存。它是辅助检查，不能代替实际切片和试打。

## 保存与导出

「保存项目」下载可编辑 JSON；「打开」读取项目文件继续。三维预览和模型下载共用当前成功生成的实体；生成未完成、结果过期或有错误时不能导出。

推荐 3MF。它包含材料、装配关系、打印预设、清单及项目副本；当前界面继续编辑的入口是项目 JSON，不是从 3MF 反向恢复。STL ZIP 依颜色分部件，位置共用坐标，不要逐个居中。

## 数据与隐私

作品的图像处理、实体计算在本机浏览器进行。进度存入 IndexedDB，公开程序资源进入独立的 Cache Storage；两类存储不能互相替代。缓存白名单不保存 HTML、API、登录或用户作品。

官方主机的模型下载事件仅发送 `{kind: "3mf"}` 或 `{kind: "stl"}`，不发送作品、文件名或访客标识。独立部署因主机白名单默认不发送。静态托管服务可能保有正常访问日志，这与应用上传作品不同。

更换浏览器、设备、域名，或清理网站数据，均可能影响本机进度。定期下载 JSON 备份；不要把本机缓存当成云备份。撤销/重做只在当前会话内存中保存。
