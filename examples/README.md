# 发行案例：百合咲

文件：[yurisaki.pass.json](yurisaki.pass.json)。项目内部名称为「百合咲」。

## 打开方式

1. 下载发行版中的独立 `yurisaki.pass.json`，或找到发行包 `examples/` 中的同名文件。
2. 打开通行证工坊；如有正在制作的作品，请先下载项目备份。
3. 点击「打开」，选择案例文件。可以切换正背面、选择图层、查看三维，或另存为自己的项目副本。

此文件是可编辑项目，不是已切片的打印文件。它不替换应用原有默认案例，也不会在下载发行包时改写浏览器里的作品。

## 案例内容

- 尺寸：50 × 100 mm；底板厚度 2.259 mm。
- 调色盘：浅蓝、白、黑、杏色四个槽；当前实体实际使用前三种材料。
- 集合：5 个正面集合、1 个背面集合，合计 33 个图案成员。
- 内容：正反面、分色图案、剪影、文字、模板装饰和裁切设置。
- 图文介绍中的正面、背面、三维和手机画面均由此文件直接导入工坊后截图。

## 打印前核对

此案例保留原设计的 8 条提示：4 个未绑定被切图案的切割工具；4 处小于 0.2 mm 的轮廓细节。未绑定的工具需要按自己的设计意图选择目标，细节应结合实际喷嘴、层高与切片预览判断。本轮只核对文件可打开、正背面和三维可显示，没有新增切片或实体试打。
